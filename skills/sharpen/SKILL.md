# Sharpen

Make the task deeper, not bigger. Before rewriting it:

1. Say what a top professional would do here that the prompt does not yet ask for.
2. Name the rawest material they would start from instead of already digested summaries.
3. Name the specific methods and available tools they would use.
4. Say what independent evidence would show that the result is right.

Then rewrite the prompt to ask for that depth inside the original boundary. Leave the user's choices open. The rewritten prompt is the deliverable; do not execute it unless requested.
