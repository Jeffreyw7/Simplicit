# Investigator brief

Inputs: one rationale question, a code/history anchor, the chosen evidence source, scope, and stopping condition. Investigate read-only using the actual available tool schemas. Do not send messages, alter documents, or delegate.

Return direct source locations or links, short relevant evidence, dates and versions, contradictions, and the query/path searched. Label each conclusion using [epistemics](epistemics.md). Explicitly distinguish an empty search, an unavailable source, and a source you did not search. Do not infer intent merely from code behavior. The lead performs final synthesis.
