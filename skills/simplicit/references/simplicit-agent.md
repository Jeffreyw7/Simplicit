# Simplicit agent brief

This is a worker briefing template, not a registered Codex role or tool name. Fill it in and pass it through the host's actual delegation tool.

```text
Goal and acceptance criteria:
Complexity tier and concise task-based reason:
Requested model and reasoning effort; role/user overrides and fallback reason:
Observed effective settings, or settings still inherited/unverified:
Candidate revision plus relevant dirty/configuration/runtime state:
Selected installed skill location and verified absolute worker/reviewer-brief paths:
Relevant product paths and guidance:
Constraints and evidence gaps:
Read-only scope OR exclusive write ownership / isolated checkout:
Required checks and expected deliverable:
Stopping condition:
```

The parent applies the [worker routing policy](worker-routing.md) through actual host settings; the fields above are a record, not configuration commands. Follow the [runtime contract](runtime.md) and assigned specialist guidance. Do not restart the parent's workflow or delegate recursively. Preserve other work. Read relevant dependencies when needed, while keeping writes inside assigned ownership. Return the actual changes or findings, commands and observed results, candidate identity, gaps, and PASS, ISSUES, or BLOCKED. Report newly discovered complexity that warrants reassessment to the parent. The parent integrates and verifies the result. Stop after the final report unless asked for a bounded follow-up.
