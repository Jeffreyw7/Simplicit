# Investigation

Load [how](../../how/SKILL.md) for runtime behavior or [why](../../why/SKILL.md) for historical rationale. Use existing findings rather than restarting either investigation.

Adapted from pstack's Investigation playbook.

Keep explanation, diagnosis, and recommendation requests read-only. Inspect the relevant source, callers, tests, and available records. Separate observed behavior from inferred intent. Cite paths or sources that support the answer.

Use a specialist only for a bounded question that materially helps the investigation. Do not automatically turn a question into a prototype, implementation, PR, or full review process. If the user also authorized a fix, finish establishing the cause and then route the remaining work to Bug fix or Change.

Deliver the answer, relevant evidence, material uncertainty, and a recommendation when requested. Match the explanation to the user's question.
